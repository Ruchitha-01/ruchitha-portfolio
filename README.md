# Ruchitha R - Personal Portfolio Website

A modern, responsive personal portfolio built with pure HTML5, CSS3 (Glassmorphism design system), and vanilla JavaScript.

---

## 🌟 Key Features

- **Glassmorphism Aesthetic**: Frosted glass cards, translucent borders, ambient glowing background gradients.
- **Dark / Light Theme Switcher**: Instant theme toggle with state persistence in `localStorage`.
- **Hero Profile Section**: Interactive dynamic typewriter effect showcasing multi-disciplinary software engineering and machine learning roles.
- **Education Timeline**: Detailed academic milestones with CGPA & percentage badges (MCA, BCA 9.13 CGPA, PU 92%, SSLC 80%).
- **Skills Matrix**: Categorized glass badges for Programming Languages, Web Frameworks, Machine Learning & AI, Database Technologies, and Tools.
- **Featured Projects Grid**: Interactive project filter tabs (*Deep Learning*, *Machine Learning*, *Data Science*) with tech stacks and links.
- **Certifications Showcase**: Grid of verified certificates from Coursera, ExcelR, and NPTEL.
- **Interactive Contact Section**: Integrated messaging handler and direct social links (GitHub, LinkedIn, Email).

---

## 🌐 How to Host on GitHub Pages (Free & Instant)

1. Create a new repository on GitHub named `portfolio` (or `ruchitha-01.github.io`).
2. Upload all the files from this folder (`index.html`, `style.css`, `script.js`, `assets/profile.jpg`, `README.md`).
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your portfolio will be live at `https://ruchitha-01.github.io/portfolio`!
